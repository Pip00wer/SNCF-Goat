# Projet : création d'une webapp Streamlit d'analyse de données

Peut-on construire un score de fiabilité par liaison, combinant taux d'annulation et retard moyen, et le représenter sur une carte du réseau ?  

- Construire le score avec les différentes variables retard/annulation/temps de trajet
- Faire la carte principale
- Trouver 2/3 axes d'appronfondissement sur le score
- Setup le streamlit (carte/viz/exploration)
- Déployer
